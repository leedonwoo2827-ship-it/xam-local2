# 시연 영상 — 사용자 지시 메모

시연 영상은 **앱 조작 장면만** 잘 보이게 찍는다. 표지, "왜 만들었나", 마무리 슬라이드는 넣지 않는다.
화면 위에는 커서 강조, 클릭 지점 확대, 작은 단계 라벨만 올린다(2026-10-24).

## 메뉴 설명에 꼭 넣을 문구 (사용자 원문 그대로)

| 메뉴 | 자막·낭독 문구 |
|---|---|
| OCR 검수 | OCR 을 하는 이유는, 수식과 표 등 다양하게 작성된 것을 매핑하기 위해서이므로, 복사가 가능한 텍스트는 다음 정리 프로세스를 더 정확하게 완료할 수 있습니다. |

| 이론 요약 노트 | 이론 요약 노트는 텍스트 위주입니다. |
| 요약반 강의 노트 | 요약반 강의 노트는 슬라이드에 의무적으로 표와 SVG 가 들어가서, 추후에 이미지화 영상을 만드는 데 기여합니다. |
| 종합반 강의 노트 | 종합반 강의 노트는 슬라이드의 양을 증폭시켜서, 추후 종합반 영상덱에 기존에 생산된 모든 산물을 모아 함께 다량의 롱폼을 만드는 데 기여합니다. 이후 미노출 종합본 HTML 을 만들고, 문제편을 제외한 초단기서의 핵심요약 HTML 까지 만듭니다. |

## 메뉴 구성 (확정 2026-10-24)

```
OCR 검수 · 구조화 MD로 정리 · 과정 정의 · 문항 집필 · 문항 교정 · 06/ 빌드(문제집)
════ 이론 묶음 (금색 · 들여쓰기) ════
  해설 모아 노트 구조화 · 이론 요약 노트 · 요약반 강의 노트 · 종합반 강의 노트
════
문항 슬라이드 제작 · 영상 제작·검수 · 인쇄본 · 06/ 빌드(해설영상)
```

- 이론 메뉴마다 그 노트의 **[노트 빌드]** 가 있다.
- 이론 메뉴는 문항 슬라이드·영상과 상관없이 따로 누를 수 있다. 앞 노트만 있으면 된다.
